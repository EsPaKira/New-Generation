# Крафты

## Как создать крафт

```ваш_пак:crafts/раздел/название_крафта.json```

Таблица с уже существующими разделами:

| Раздел     | Где используется     |
| ---------- | -------------------- |
| primitive  | Доступен везде       |

*Будет расширяться со временем*

Пример крафта из ```newgen:crafts/primitive/stick.json```:

```json
{
    "components": [
        {"tag": "newgen:wood-craft", "count": 1}
    ],
    "results": [
        {"id": "newgen:stick", "count": 8}
    ]
}
```

```components```, как и ```results``` - массивы, следовательно, могут вмещать в себя множество элементов. В базовом интерфейсе крафтов отображается картинка первого из ```results```.

В ```components``` есть два вида материалов: ```id``` - просто тектовый id предмета и ```tag``` - группа предметов с одинаковым тегом. Рекомендуется делать теги с ```-craft``` на конце во избежание ненужных совпадений и указывать их в ```ваш_пак:tags.toml``` (см. [документацию VoxelCore](https://github.com/MihailRis/voxelcore/blob/release-0.32/doc/ru/item-properties.md#теги---tags)).

[!WARNING]
>Не указывайте ```tag``` в ```results```.

Таблица с уже существующими тегами:

| Тег                | Пример предмета                |
| ------------------ | ------------------------------ |
| newgen:wood-craft  | newgen:spruce, base:wood       |

*Будет расширяться со временем*

## Как изменить крафт

Существующие крафты можно изменять. Для этого в ```components``` и ```results``` укажите новые материалы. Так как крафты собираются через движковый ```file.read_combined_object()``` (см. [документацию](https://github.com/MihailRis/voxelcore/blob/release-0.32/doc/ru/scripting/builtins/libfile.md#контент-паки)), при необходимости достаточно заменить только ```components``` или только ```results```.
