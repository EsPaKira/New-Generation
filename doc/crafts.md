# Крафты

Крафты добавляются в папку crafts (либо в контент-паке New Generation, либо в вашем паке).

Если хотите дополнить уже существующие крафты, в папке crafts вашего контент-пака создайте json-файл с тем же названием.

Крафты из primitive_crafts.json доступны везде; остальные крафты доступны в своих верстаках.

*Крафты для печек объявляются только в melting_crafts.json*


## Шаблон для json-файла крафтов:

```json
[
    {
        "components": [
            {"id": "ID_контент-пака:ID_предмета", "count": 777}, ...
        ],
        "results": [
            {"id": "ID_контент-пака:ID_предмета", "count": 777}, ...
        ]
    }, ...
]
```

## Материалы

Так же доступны крафты по материалам (сейчас в New Generation всего 5 видов материалов: wood, planks, pebble, stone и flower). в таком случае в components вместо "id": "ID_контент-пака:ID_предмета" пишется "tag": "название_tag", где название_tag - wood, pebble или ваш материал.

Чтобы добавить свой материал, в json-файле предмета добавьте поле:

```json
{
    "newgen:craft-material": "название_материала"
}
```

Можно добавлять материалы предметам из других паков. Ещё можно добавить описание для материала и изображение (нужно в меню крафтов).

Изображение необходимо добавить в папку textures/gui и указать в preload.json:

```json
{
    "textures": [
        "gui/название_изображения_без.png"
    ]
}
```

Чтобы добавить описание, необходимо создать папку materials и добавить в неё название_файла.txt

>[!IMPORTANT]
> Название материала, название изображения и название файла с описанием должны совпадать.
> В будущем возможны изменения в том, как создавать материалы. 

## Шаблон скрипта для блока-верстака
Блок-верстак - любой блок, при [ПКМ] по которому открывается меню крафтов

```lua
function on_interact(x, y, z, pid)
    -- crafts_id - название файла с крафтами без "crafts/" и ".json"
    -- для "crafts/workbench_crafts.json" crafts_id будет "workbench_crafts"
    hud.show_overlay("newgen:crafts", false, {crafts_id})
    return true
end
```
