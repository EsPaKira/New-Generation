# Конфигурация New Generation

Все параметры настраиваются через config/newgen/main.json

## Урон при удушье

Урон, который наносится, когда заканчивается кислород.

Базовое значение - 10000

Ключ - ```"suffocation-damage"```

### Пример *config/newgen/main.json:*

```json
{
    "suffocation-damage": 10 --наносит 10 урона в секунду, когда закончится кислород
}
```

## Время в бою

Отвечает за время (в секундах), в течение которого игрок/моб находится в бою после получения урона. Необходимо для некоторой игровой логики (например, регенрация HP).

Базовое значение - 10

Ключ - ```in-battle-time```

## Время регенерации

Отвечает за интервал (в секундах), в течение которого игрок/моб восстанавливает HP.

Базовое значение - 1

Ключ - ```regen-time```

## Время увеличения голода

Отвечает за интервал (в секундах), в течение которого у игрока/моба голод увеличивается на 1.

Базовое значение - 120

Ключ - ```hunger-time```

## Меню смерти

Ключ - ```death-menu```. Просто указать XML-файл (Например: ```newgen:death_menu``` без .xml).

## Боковая панель

Та самая панель, которая появляется слева от инвентаря. *Будет добавлено позже*

## Фоны интерфейса

Можно добавить новые фоны интерфейса. Пример реализации в ```newgen:config/newgen/backgrounds.json```. Не забудьте указать фоны в ```ваш_пак:preload.json```.

В ```ваш_пак:config/newgen/main.json``` можно указать фон по умолчанию через ```standard-background```. *По умолчанию отображается фон из config:newgen/background.txt, если есть. Он общий на все миры*
